# Demo Assets

This directory is reserved for synthetic datasets, screenshots, and other demo-safe assets.

Rules for anything added here:
- no real prompts
- no real project paths
- no copied transcript text
- no private ticket IDs
- no screenshots that reveal private repositories or working habits

The first implementation pass should add a fictional dataset here before the real ingest path is introduced.

The current synthetic dataset lives in:
- `src/lib/sessionlens/demo-fixtures.ts`

That keeps the scaffold easy to import while the repo is evolving toward broader launch.

Committed demo-safe visual assets:
- `sessionlens-dashboard-hero.png`
- `sessionlens-dashboard-poster.svg`
- `sessionlens-social-preview.svg`

These exist so the repo can be explained on GitHub with demo-safe visuals from day one.
